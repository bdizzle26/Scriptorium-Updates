# Scriptorium downloads

This repository distributes official Scriptorium installers and update metadata. Application source code and user projects are not stored here.

## Windows

Windows releases contain `Scriptorium-Setup.exe`, `windows-update.json`, and checksums. Download installers from the Releases page. The first Windows release is unsigned.

Automatic update checks are optional and disabled by default. Manual checks are available in Settings → Updates. Installation requires confirmation, saves pending work, and creates a local backup first. Normal upgrades and uninstall retain user data.

Keep independent project and voice-archive backups. Windows releases are not marked as GitHub’s Latest release, so they do not replace the Android update channel’s latest-release pointer.

## Android

Android releases, when available, retain their separate signed APK and `latest.json` update feed.
